# PolyBatch

[English](README.md) · **中文**

**在 Polymarket 上一键批量下单多个选项。** 在一个市场里勾选多个选项,设定方向(YES/NO)和每个选项的股数,实时看到综合成本,然后一次性把所有订单下完——不用再一个个手动点。

> ⚠️ **非官方。** PolyBatch 是独立的社区工具,**与 Polymarket 没有任何隶属、背书或关联关系**。

## 工作原理——以及为什么安全

PolyBatch **绝不接触你的私钥或资金**,它不签任何东西,也没有后端服务器。

它做的是驱动 Polymarket 自己的界面:替你填入价格和股数、点击各个选项的 *Place order*,由**你自己**已连接到 Polymarket 的钱包来签署每一笔订单——和你亲手操作完全一样。因为签名完全交给你连接的钱包,PolyBatch 支持 Polymarket 支持的**任意**钱包(MetaMask、Magic 邮箱登录、Phantom 等)。

一切都在你的浏览器本地运行。它是开源的,以上这些你都可以自己查验。

## 安装

**从源码加载(加载已解压的扩展):**

1. 下载本仓库(Code → Download ZIP,或 `git clone`)。
2. 在 Chrome 打开 `chrome://extensions`。
3. 打开右上角的**开发者模式**。
4. 点**加载已解压的扩展程序**,选择本项目文件夹。
5. 打开任意 Polymarket 市场页——PolyBatch 面板会出现在右侧。

仓库里预打包好的 `polybatch-ext.zip` 就是同一份东西的压缩包。

## 使用

1. 打开一个含多个选项的 Polymarket 事件页。
2. 在 PolyBatch 面板里:选 **YES** 或 **NO**,设定每个选项的股数,勾选想买的选项。
3. 查看综合成本(绿色 = 可获利,红色 = 会亏)。
4. 点 **Place orders**,每笔订单弹出时在钱包里签名。

点 **×** 关闭面板;之后随时点浏览器工具栏的 PolyBatch 图标把它重新召唤出来。

### 关于定价

订单以**限价单**下出,限价会挂到能吃穿你所填股数深度的档位——如果你的股数超过卖一档,限价会挂得足够高以扫掉更深的档位,Polymarket 会先成交更便宜的。超出全部可用深度的部分可能不会成交。
